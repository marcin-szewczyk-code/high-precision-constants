# High-precision constants

Playing with mathematical constants (e, pi) through high-precision computation.

Related blog post (e – one million digits):
[https://blog.marcinszewczyk.net/posts/e-number-one-million-digits/](https://blog.marcinszewczyk.net/posts/e-number-one-million-digits/)

## Contents

- `src/e/` – computing **e** (Taylor series expansion)
- `src/pi/` – computing **pi** (Leibniz series, Ramanujan series, Chudnovsky algorithm – planned)
- `latex-book/` – LaTeX book (methods and printable digits – planned)
