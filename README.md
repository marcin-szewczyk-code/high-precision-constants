# High-Precision Constants

High-precision computation of mathematical constants (e, pi) with a companion LaTeX book project.

This project combines numerical computation with a printable LaTeX book that includes an introduction, a description of the methods used, and high-precision digit expansions (up to one million digits).

Related blog post (e – one million digits):
[https://blog.marcinszewczyk.net/posts/e-number-one-million-digits/](https://blog.marcinszewczyk.net/posts/e-number-one-million-digits/)

## Contents

- `src/` – source code for computing constants
  - `e/` – computing **e** (Taylor series expansion – planned)
  - `pi/` – computing **pi** (Leibniz series, Ramanujan series, Chudnovsky algorithm – planned)
- `latex-book/` – LaTeX project for printable high-precision digit expansions (planned)
